# プロポーザル: XHTML5+MEI エディタのUX改善と修正

## 概要
実装されたXHTML5+MEIエディタに対し、ユーザーフィードバックに基づいた大幅な改善を行います。
「既存のレンダリング結果と同一の見た目」を実現し、閲覧モードと編集モードを切り替え可能なUIへと変更します。
また、MEIレンダリングエラーや構造化の不具合（タグがテキストになる問題）を解決するため、ASTパーサーのロジックを根本的に見直します。

## 修正された動機
当初の実装では、エディタの見た目が素のProseMirrorであり、既存のレンダリング結果と乖離していました。また、MEIの埋め込み処理に不具合があり、楽譜が表示されていませんでした。これらを解消し、ユーザーが期待する「直感的で、かつ既存の表示と違和感のない編集体験」を提供する必要があります。

## 提案される変更

### 1. UX/UI の改善
- **見た目の統一**: ProseMirrorのレンダリングに既存のCSS (`main-content.css` 等) を適用し、閲覧モードと区別のつかない高品質な表示を実現します。
- **モード切り替え**: ヘッダー（またはツールバー）に「閲覧モード（Read）」と「編集モード（Edit）」の切り替えスイッチを設置します。
    - **閲覧モード**: 既存の `DocumentView` を使用（読み取り専用、最速レンダリング）。
    - **編集モード**: `SplitEditor` を使用。左側はWYSIWYG、右側はXMLソース。
- **同期の修正**: ワークスペースでファイルを選択した際、右側のCodeMirrorも正しく更新されるように修正します。

### 2. 技術的負債の解消とバグ修正
- **ASTパーサーの刷新**:
    - `sax-js` のイベントによるタグ再構築をやめ、**位置情報（position）を用いた部分文字列抽出（substring）** に切り替えます。これにより、MEI内部の構造やXHTMLのタグ構造を完全に維持したままASTに取り込みます。
    - これにより、`No <body> element found` エラーや、タグがテキスト化する問題を解決します。
- **Verovio統合の修正**:
    - 抽出された完全なMEI文字列を Verovio に渡すようにし、描画エラーを解消します。

## 変更されるファイル
- `frontend22/src/lib/editor/ast/parser.ts`: パースロジックの変更。
- `frontend22/src/components/editor/SplitEditor.tsx`: 同期ロジックと表示の修正。
- `frontend22/src/components/center/Main.tsx`: モード切り替えの実装。
- `frontend22/src/lib/editor/schema/xhtml-mei.ts`: 見た目を合わせるためのDOM構造定義の調整。
