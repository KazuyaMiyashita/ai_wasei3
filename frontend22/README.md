# Music Analysis Integration フロントエンド部分

Verovioを用いた楽譜表示・編集・アノテーション付与・分析結果表示等を行うアプリケーション。

frontend/ 以下のディレクトリにある。

現在は src/ 以下にデザインのみが存在し、 old-src/ 以下に古いプロトタイプが存在する。

もくろみ

- 文章と楽譜が混在したドキュメントを管理する
- Web上のリソースを参照する
- 楽譜の表示・編集・再生を行う
- 楽譜へのアノテーションの付与、分析結果の表示、自動作曲を行う
- マイク入力から楽譜を自動で入力

## モデリング

ワークスペース・セッション・ドキュメント

### MusicDocument

以下の2つのいずれかの形式の文章。いずれもXMLである

- MEI: Music Encoding Initiative(MEI) による楽譜。拡張子は .mei
- XHTML5+MEI: XHTML5によるドキュメントで、文章の中に複数のMEIのXMLを含みうる。拡張子は .xml

いずれもセッションで MusicDocument が選択されると Main コンポーネント内にレンダリングされたHTMLを配置する。

### セッション

閲覧・編集中の MusicDocument の一覧の管理。ドキュメントの編集履歴。
選択中の MusicDocument を最大で1つ持つ。
その他、言語の設定など。

### Workspace

ローカルファイルのフォルダ・ディレクトリを模した構造で、セッションで保存したドキュメントの一覧を管理する。
デフォルトでローカルストレージと同期がされるが、FileSystem APIを利用してユーザーが指定したローカルのディレクトリと同期可能にする。

## Features

### MusicDocument のレンダリング

MusicDocument はWebで表示可能な形にレンダリングされる。

形式がMEIの場合、Verovioを利用してSVGに変換する。

XHTML5+MEIの場合は `<body>` 要素より下の要素を抽出し、その中の `<mei xmlns="http://www.music-encoding.org/ns/mei">` をそれぞれVerovioを用いて
SVGに変換し、出来上がったHTML5形式の文章をMainに配置する。サニタイズを行い、スクリプトが実行されないようにする。

Verovioを利用した後、音符をクリックして編集や再生ができるようにDOMが追加される。

### 楽譜の編集

メインエリアに表示されている楽譜は、音符をクリックすることで該当部分のMEIのXMLがInspectorに表示され、以下の方法で編集できる

- XMLを直接編集する。
- 音符の上下移動や挿入・削除など、キーボード入力やNote Paletteからの入力

いずれの編集も (楽譜全体のXML, 選択対象のID、選択部分の変更後のXML) => 楽譜全体のXML というインターフェースで行う。

### 再生

音符を選択した時、または再生ボタンを押した時に音を鳴らすことができる

## UI

### パネル

画面の LeftRail から選択できるもの。

- Workspace: モデルのWorkspaceと対応する
- Templates: 組み込みのテンプレートとなる MusicDocument の一覧を表示し、選択するとセッションに追加する。
- Explorer: 指定したURLにあるインターネット上の MusicDocument の一覧を表示し、選択するとセッションに追加する。
- Inspector: セッションで選択中のドキュメントの、特定の楽譜に対し、選択している音符などの情報を表示する。
- Note Palette: 音符アイコンのボタンの一覧を表示し、セッションで選択中のドキュメントの、特定の楽譜の特定の選択部分に対し、編集を行う
- Settings: 言語の設定など。

### タブ

セッションの中で開いているファイルの一覧を表示する

### メインエリア

セッションでドキュメントが選択されている場合、該当のドキュメントを表示する。
セッションでドキュメントが選択されていない場合は、Welcomeページを表示する。

### ヘッダー

ロゴ、メニュー、楽譜の編集に関するツール一覧、再生ツール一覧。

### フッター

ログなどを表示する。
