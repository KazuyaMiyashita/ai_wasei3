# 実装タスク

- [x] **タスク 1: RST 統合と排他制御の基盤** <!-- id: init-lock -->
  - `EditorController` に `RST` を統合する。
  - 状態管理 (`Idle`, `ProcessingFromCM`, `ProcessingFromPM`) を実装する。
  - ログ記録機能 (`LogEntry`) を実装する。
  - **テスト**: ロック状態の遷移、ログの記録に関する単体テスト（3単純/3複雑）。
  - `pnpm check`

- [x] **タスク 2: CM -> RST -> PM 同期 (MEI表示含む)** <!-- id: cm-sync -->
  - CM の変更を RST に反映する。
  - ProseMirror スキーマを更新し、`mei` ノードを定義（Atom/Pre表示）。
  - `rst.toProseMirrorDoc` を実装し、MEI ノードを適切に変換する。
  - RST から PM への同期処理を実装する（ロック制御含む）。
  - **テスト**: テキスト挿入、削除、MEI ブロックの表示確認（3単純/3複雑）。
  - `pnpm check`
- [x] **タスク 3: PM -> RST マッピング (挑戦的タスク)** <!-- id: pm-mapping -->
  - ProseMirror の Transaction を解析し、RST の編集操作へ変換するロジックを実装する。
  - **検証ポイント**: PM での文字入力が、再パースなしで RST の正しい位置に反映されるか。
  - **中断判断**: マッピングが不可能と判断された場合、設計変更案を作成して終了する。
  - **テスト**: カーソル位置の同期、属性変更、ネストされたノードの編集（3単純/3複雑）。
  - `pnpm check`

- [x] **タスク 4: PM -> RST -> CM テキスト同期** <!-- id: pm-sync-apply -->
  - タスク3で更新された RST から、CodeMirror のテキストを更新する。
  - 可能な限り差分更新（または全置換だがカーソル維持）を行う。
  - **テスト**: PM での編集が CM に反映され、CM のカーソルが飛ばないこと（3単純/3複雑）。
  - `pnpm check`

- [x] **タスク 5: デバッグビューと UI フィードバック** <!-- id: ui-debug -->
  - `EditorControllerDebugView` に「Logs」タブを追加し、イベントログを表示する。
  - 「RST」タブでツリーを表示する。
  - ロック中、操作できないエディタのカーソルスタイルを変更する実装を行う。
  - **テスト**: ログが正しく表示されるか、ロック時にスタイルが適用されるか。
  - `pnpm check`

- [x] **タスク 6: 最終検証とレポート** <!-- id: finalize -->
  - 統合テストシナリオの実行。
  - 実装レポート（アルゴリズム詳細、制限事項）の作成。
  - デモンストレーション（操作手順書またはスクリプト）の作成。
