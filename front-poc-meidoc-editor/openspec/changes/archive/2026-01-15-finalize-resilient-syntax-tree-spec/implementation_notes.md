# ResilientSyntaxTree 実装概要と改善案

## 1. 概要 (Overview)

`ResilientSyntaxTree` (RST) は、XMLベースのドキュメント（XHTML, MEI等）を、その構造が一部破損している状態（編集中）であっても損失なく保持し、エディタ間（CodeMirror <-> ProseMirror）で効率的に同期させるための中間データ構造です。

### 主な特徴

- **寛容性 (Lenient Parsing)**: 閉じタグ忘れや属性値の引用符ミスなどを許容し、エラーノードとして構造化します。
- **可逆性 (Lossless Round-trip)**: 空白、改行、インデント、引用符の種類など、あらゆる文字情報を保存し、再構築時に1バイトの差異も生じさせません。
- **厳格な増分更新**: CodeMirror の編集操作に対し、全文再パースを行わず、影響範囲のみを高速に更新します。不整合が生じた場合は即座に例外を投げ、データの静かな破損を防ぎます。
- **スキーマ非依存**: 任意のタグ定義や Void Element 定義を注入可能で、複合的な XML ドキュメントに対応します。

## 2. 実装詳細 (Implementation Details)

### 2.1 データ構造 (`ResilientNode`)

4つのノードタイプにより、あらゆるテキスト断片を分類します。

- **Defined**: スキーマで定義されたタグ（例: `<section>`, `<note>`）。
- **Foreign**: 未知のタグ（例: `<unknown>`）。
- **Text**: テキストコンテンツ。
- **Error**: 構文エラー（孤立した閉じタグ、不整合なタグなど）。

### 2.2 アルゴリズム

- **パース**: スタックマシンを用いたワンパスの走査。
- **編集 (Edit)**:
  1.  変更範囲 (`from` 〜 `to`) を含む最小の親ノード (`lowestCommonAncestor`) を特定。
  2.  その親ノードの範囲内で、変更後のテキストを用いて部分的に再パース。
  3.  既存の子ノードリストを新しいパース結果で置換 (splice)。
  4.  後続の全ノードに対し、長さの差分 (`delta`) だけ座標 (`range`) をシフト。
- **検証**: 各操作後に「ルートからの文字長合計」と「実際の文字列長」が一致するかを検証。不一致なら `RSTIntegrityError`。

## 3. 改善の余地 (Areas for Improvement)

### 3.1 座標更新のパフォーマンス (O(N) -> O(log N))

現在の設計では、ノードの座標 (`range.from`, `range.to`) を絶対値で持っているため、ドキュメント前方の編集により、後方のすべてのノードの座標を更新する必要があります (O(N))。
**改善案**:

- 各ノードには「親からの相対オフセット」または「自身の長さ」のみを持たせ、絶対座標が必要な時だけ計算する、あるいは「Gap Buffer」や「Piece Table」的な構造を取り入れることで、座標更新コストを削減可能です。ただし、検索コストとのトレードオフになります。

### 3.2 メモリ効率

すべてのテキストを `ResilientNode` オブジェクトとしてラップするため、巨大なテキスト（数MB以上）ではメモリオーバーヘッドが大きくなる可能性があります。
**改善案**:

- 純粋なテキスト部分が続く場合、細かい `TextNode` に分割せず、可能な限り大きなチャンクとして保持する最適化。
- Flyweight パターンの適用（共通の属性オブジェクトなど）。

### 3.3 ProseMirror Transaction の完全なマッピング

ProseMirror の変更（特に複雑な Schema 制約による自動修正や、複数のノードにまたがる置換）を RST に正確に戻すのは高難易度です。
**改善案**:

- 現在は基本的なテキスト挿入・削除と構造変更のみを想定していますが、ProseMirror の `Step` をより詳細に解析し、RST 側の操作に変換する専用の「リバース・マッパー」を強化する必要があります。

### 3.4 エラー回復戦略の高度化

現在は「スタックと合わない閉じタグ」は即座にエラーまたはテキストとして扱いますが、HTML5 パーサーのように「ある程度遡って閉じる（Auto-closing）」戦略を導入することで、ユーザーの意図に近い解釈が可能になる場合があります。
